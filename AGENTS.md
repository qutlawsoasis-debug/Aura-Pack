# Aura-Pack — Правила репозитория сборки модов (AGENTS.md)

Официальная сборка модов, шейдеров, ресурспаков и конфигов для **Aura Launcher**.
Целевая платформа: **Minecraft 1.20.1**, **Fabric Loader 0.19.5**.

---

## 1. Структура и режимы синхронизации (`manifest.json`)

- `mods/`, `shaderpacks/`, `resourcepacks/` — синхронизируются в режиме `"sync"` (лаунчер скачивает/заменяет файлы при расхождении SHA-256 и удаляет лишние `*.jar` из `mods/`).
- `config/*` и `options.txt` — синхронизируются в режиме `"default"` (создаются только если файла у игрока ещё нет; существующие настройки игрока не перезаписываются).
- Исключение: пути, явно перечисленные в `forceConfigs` внутри `pack.settings.json`, получают режим `"sync"` и перезаписываются всегда.

---

## 2. Строгие правила и ограничения

1. **Никаких личных данных в `config/` и `options.txt`**:
   - Запрещено коммитить локальные пути (`C:\Users\...`, `D:\`), никнеймы, IP-адреса, токены или привязки клавиш игрока.
   - В `options.txt` хранятся только базовые дефолты для первого запуска (`version`, `lang:ru_ru`, `guiScale:2`, `fullscreen:true`, `resourcePacks`).
2. **Известные конфликты и патчи модов**:
   - Мод **NoExpensive (`NE-1.20.1-1.9.0.jar`) строго запрещён** — вызывает Mixin-краш в паре с `no_xp_anvils`.
   - В архив `mods/alexsmobs-2.2.2-fabric+1.20.1.jar` вшиты недостающие теги предметов (`c:nuggets/iron`, `c:ingots/iron`, `c:ingots/netherite`, `c:rods/wooden`, `c:strings`, `c:glass_blocks`) для работоспособности всех крафтов *Alex's Mobs*. При обновлении этого JAR-файла обязательно сохранять эти теги.
3. **Манифест (`manifest.json`)**:
   - Никогда не редактируй `manifest.json` вручную.
   - Для пересчёта манифеста используй `.\tools\make-manifest.ps1`.
   - Для полной публикации изменений (пересчёт SHA-256, `packVersion`, коммит и пуш в `main`) используй:
     ```powershell
     .\tools\publish.ps1 -Yes
     ```
