# Wex Pack

Сборка модов, ресурсов и конфигураций для Minecraft **1.20.1** и **1.21.1**, Fabric Loader **0.19.5**.

Пак совместим с прежним лаунчером. Имя репозитория **Aura-Pack** и raw GitHub пути сохраняются для совместимости доставки.

## Профили

| Minecraft | Манифест | Файлы |
|---|---|---|
| 1.20.1 | manifest.json | mods/, config/, resourcepacks/, shaderpacks/ |
| 1.21.1 | manifest-1.21.1.json | versions/1.21.1/ |

Клиент поставляется в mods каждого профиля. Wex Defaults сохраняет игровые правила, блокировку cheats, host ban и уведомления об обновлениях; меню и предупреждения мира обрабатываются клиентом и Minecraft.

## Синхронизация

- mods, resourcepacks и shaderpacks используют mode=sync: проверка SHA-256, размера и удаление устаревших jar средствами лаунчера.
- config и options.txt используют mode=default: обычное обновление сохраняет существующие настройки игрока.
- forceConfigs в pack.settings.json явно задаёт обязательные sync-конфигурации.
- Ручная полная проверка прежнего лаунчера может восстановить и default-файлы; учитывайте это перед восстановлением установки.
- Для старого лаунчера важен локальный path файла в raw GitHub. Поле url дополнительно хранит адрес будущего release asset.

## Обновление манифестов

Манифесты генерируются инструментом, вручную их не редактируют:

```powershell
.\tools\make-manifest.ps1 -TargetVersion 1.20.1
.\tools\make-manifest.ps1 -TargetVersion 1.21.1
.\tools\check-parity.ps1
```

Для импорта нового клиента передайте -ClientReleaseDir с release-manifest.json и обоими jar. Генератор проверяет оба профиля и сохраняет SHA-256/size. Исходники Wex Defaults и инструкция сборки находятся в tools/wex-defaults/.

## Состав

Пак содержит оптимизацию Sodium/Lithium/ModernFix, Iris, карты Xaero, моды генерации мира и приключений, пространственный звук, ресурспаки и настройки. Подробный фактический состав каждой версии находится в её манифесте; различия между версиями документируются в tools/parity-exceptions.json.

Не копируйте в репозиторий личные миры, токены, адреса серверов и пользовательские настройки. Лицензия инфраструктуры — [MIT](LICENSE); моды и ресурсы сохраняют лицензии авторов.
